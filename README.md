# SET111 / MCT221 - Digital Design

**Instructor: Dr. Ahmed Reda Mohamed**

Lecture materials for **Digital Design**, covering the foundations of digital logic and the analysis and design of combinational and sequential circuits. This repository contains **12 individual lecture PDFs** and the **complete course pack** for convenient study and revision.

## Course topics

The lectures develop the following topics in sequence:

1. **Digital fundamentals:** analog and digital quantities, logic levels, waveforms, and programmable and fixed-function logic devices.
2. **Number systems:** decimal, binary, octal, and hexadecimal representations; conversions; binary arithmetic; and complements.
3. **Logic and simplification:** logic gates, Boolean algebra, De Morgan's theorems, truth tables, standard forms, Karnaugh maps, and don't-care conditions.
4. **Combinational circuits:** gate-level implementation, adders and subtractors, encoders and decoders, multiplexers, and demultiplexers.
5. **Sequential circuits:** latches, flip-flops, timers, finite state machines (FSMs), and asynchronous and synchronous counters.

## Using the materials

Start with the course introduction, then follow the lecture order. Use the individual PDFs to review a particular topic or the combined course pack to read the full sequence. Practice the exercises as you progress from Boolean simplification to circuit implementation and counter design.

All materials are in PDF format and can be opened in a browser or PDF reader. For offline study, download the PDFs or the repository ZIP.
